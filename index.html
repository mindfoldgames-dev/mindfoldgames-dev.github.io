How to Play

Simple to learn, impossible to put down

Tap an Arrow

Each arrow points in one direction. Tap it and it flies off — but only if the path is clear!

Clear the Path

Remove blocking arrows first to create escape routes. Think ahead and plan your moves.

Solve the Puzzle

Clear all arrows from the board to earn stars. Fewer taps = more stars = more coins!

Earn Rewards

Collect coins, unlock power-ups (hints, magnets, compasses), and conquer Boss Levels for 3× rewards.
